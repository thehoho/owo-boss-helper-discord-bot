# v0.16.9-beta — Clearer H XP Guide

The `H XP` guide now uses shorter, natural B2-level English and a compact aligned table for its Knowledge-switch comparison.

The table clearly states that it shows direct extra XP for one pet equipped with 15% Knowledge. It presents the 1,000- and 10,000-streak results side by side, and the values in parentheses show the required number of weapon switches.

This release also removes the unnecessary sentence about battle-loss risk and replaces the redundant calculation explanation with a simple description of what the table provides.

Heather's Pet EXP guide remains named and linked in the credits. All formulas and calculated totals are unchanged.

No database migration, slash-command schema change, dependency update, or new Discord permission is required.
