# v0.16.22-beta — Compact Top.gg Vote Messages

Top.gg vote notifications are now quicker to read.

- Thank-you DMs show the user's recorded votes, vote points, and next-vote time.
- Reminder DMs use one short line.
- The existing **Vote on Top.gg** and **Turn off vote reminders** controls remain available.

This release changes presentation only. Vote imports, history, points, and reminder scheduling work as before.
