# v0.16.10-beta — XP Scope and Current TapDeck Card

`H XP` now explains the multiplier's scope with one direct rule: it applies only to battle XP on the primary team. This wording also makes clear that secondary-team, boss, hunt, and fixed daily XP are outside that multiplier without listing every exception.

The TapDeck Lite card now matches the current Google Play version. It covers up to 40 saved command keys, customizable keyboard and button colors, global or per-key delays and cooldowns, guarded slash-command sending with an optional retry, and optional 24-hour clipboard history.

Google Play is now the card's only installation path. The old GitHub APK and source buttons are removed, along with the runtime GitHub release lookup, so `H Grind`, `H TapDeck`, and `/tapdeck` open immediately without depending on GitHub's API.

The privacy section now reflects the Google Play declaration that no data is collected or shared, while retaining the app's offline, permission-free, private-local-storage details.

No XP formula changed. No database migration, slash-command schema change, dependency update, or new Discord permission is required.
