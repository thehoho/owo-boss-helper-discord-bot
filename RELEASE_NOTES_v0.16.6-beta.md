# v0.16.6-beta — Compact Team XP Controls

This release reduces visual clutter under the Team XP panel while keeping every existing action available.

## One compact row

- **XP Calculator** remains labeled.
- **⚔️** saves the currently displayed weapons as the normal preset in one click.
- The **Knowledge icon** opens replacement weapon inputs.
- **🔔** opens the private reminder settings.
- **💾** privately explains how to import and save the replied-to OwO team.

## Clear Knowledge replacement

Each Knowledge input shows the current normal weapon ID and animal. Members enter only the six-character replacement Knowledge IDs they want to change; untouched positions continue using their normal weapon.

Saving either preset still disables reminder tracking until the member explicitly enables it again. No database migration, dependency update, slash-command schema change, or new permission is required.
